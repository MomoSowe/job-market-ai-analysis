# Dataset sources

## `ai_job_trends_dataset.csv` — synthetic

Generated by [`build_datasets.py`](build_datasets.py) (seeded, reproducible).
Same column schema as the original file it replaced, so `main.py` runs
unchanged. Job titles are sampled from the real occupation list below
(weighted by real employment size); every other field is simulated with
**documented, intentional relationships** rather than random noise —
see the comments in `build_datasets.py` for the exact formula behind each
column. Automation Risk correlates with Median Salary (-0.50), Experience
Required (-0.64), and Remote Work Ratio (-0.45); Gender Diversity is left
deliberately uncorrelated (no real, non-stereotyped basis to tie it to
anything).

Regenerate with: `python data/build_datasets.py`

## `real_automation_risk_by_occupation.csv` — real

Cleaned from Plotly's public datasets repo (MIT-licensed):
https://github.com/plotly/datasets/blob/master/job-automation-probability.csv

That file joins two real sources:
- Frey, C. B. & Osborne, M. A. (2013), *"The Future of Employment: How
  Susceptible Are Jobs to Computerisation?"* — per-occupation
  computerisation-probability estimates (`automation_probability`, 0–1).
- U.S. Bureau of Labor Statistics, Occupational Employment Statistics,
  May 2016 — employment counts and wages by SOC code.

700 U.S. occupations, SOC-coded. No values were invented; only column names
and duplicate columns were tidied. Analyzed in `main_real.py`.

## Removed: original `ai_job_trends_dataset.csv`

The dataset originally in this repo (Kaggle-sourced, unknown generation
method) had two problems surfaced during analysis:
1. It contained joke/placeholder job titles unrelated to real employment
   data (e.g. "Dancer", "Psychotherapist, dance movement") — removed on request.
2. All numeric fields were close to mutually uncorrelated (e.g. Remote Work
   Ratio vs Automation Risk: r = 0.004), consistent with independently
   randomized columns rather than a modeled relationship — this made most
   charts built from it show noise, not signal. That's the reason it was
   replaced rather than just re-cleaned.
